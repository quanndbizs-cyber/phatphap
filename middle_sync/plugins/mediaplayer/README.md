# MediaPlayer & Content Kit Plugin for Typemill

Plugin đa phương tiện hỗ trợ phát Audiobookshelf, Audio.com, YouTube, MP3 cục bộ, giao diện Tab Kép (BuhdView) và quản lý thiết lập trực quan trên Backend Typemill.

## Tính năng chính
- **Backend Visual Settings**: Tích hợp trực tiếp vào thanh công cụ Metadata trong trang quản trị Typemill (`metatabs: mediaplayer`). Cho phép thiết lập tiêu đề, mã album Audiobookshelf, link ngoài, đường dẫn đọc sách/PDF, chế độ tự động hiển thị mà không cần can thiệp code hay gõ shortcode.
- **Giao diện Tab Kép (`[:buhdview:]`)**: Chuyển đổi mượt mà giữa Tab phát Audio MP3 danh sách bài và Tab Tóm tắt truyện / Đọc sách / Video.
- **Trình phát Audiobookshelf (`[:absplayer:]`)**: Tích hợp danh mục `abs_catalog.json`, hỗ trợ tìm kiếm bài, tự động phát bài tiếp theo, thanh tua seekbar, chọn tốc độ phát.
- **Bảng tra cứu bài giảng (`[:storylist:]` & `[:tracklist:]`)**: Lọc tìm kiếm thời gian thực, tự động gắn nút Nghe MP3, Tải file, Đọc sách trực tuyến và mở Video YouTube.
- **Trung tâm MediaHub đa tập (`[:mediahub:]`)**: Sidebar duyệt danh mục nhiều tập kết hợp stage phát nội dung bên phải.
- **Accordion (`[:accordion:] ... [:/accordion:]`)**: Khối nội dung đóng mở gọn gàng.
